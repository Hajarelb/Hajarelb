## 📂 Featured work

### [LiveChat DevSecOps pipeline](https://github.com/DevSecOps-G2/workshops-groupe2) · group project of 3, in progress
Securing a Java/Maven web application (Jakarta EE, WebSocket, MySQL) from code to container, as part of the Master's DevSecOps module.
- **SAST**: SonarQube and Semgrep, run on every push and pull request with GitHub Actions
- **SCA**: Dependabot and OWASP Dependency-Check; a MySQL connector CVE fixed by upgrading the dependency
- **DAST**: OWASP ZAP scans integrated in CI; an XSS vulnerability confirmed manually; risks prioritized with DREAD and the OWASP Top 10
- **Container security**: Trivy scans, Dockerfile hardening (non-root user, HEALTHCHECK) and a HIGH/CRITICAL blocking threshold in the pipeline

### [ShopEase](https://github.com/Hajarelb/Project-Android-ShopEase) · mobile e-commerce app
Android app built with Kotlin and Jetpack Compose, with product catalog, authentication and cart, using Supabase as backend.

### DevOps lab work · Master's program

- Jenkins CI/CD pipelines for a Spring Boot app (Maven, OWASP Dependency-Check, SonarQube, Docker Hub) with deployment through Ansible
- Ansible playbooks and roles; monitoring with Prometheus, Grafana and Node Exporter
- Docker (multi-stage images, Compose, private registry), Docker Swarm and Kubernetes (Deployments, Services, Ingress, volumes, CronJob, HPA)
