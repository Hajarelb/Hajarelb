## Featured work

Securing a Java/Maven web application (Jakarta EE, WebSocket, MySQL) from code to container, as part of the Master's DevSecOps module.
- **SAST**: SonarQube and Semgrep, run on every push and pull request with GitHub Actions
- **SCA**: Dependabot and OWASP Dependency-Check; a MySQL connector CVE fixed by upgrading the dependency

- **Container security**: Trivy scans, Dockerfile hardening (non-root user, HEALTHCHECK) and a HIGH/CRITICAL blocking threshold in the pipeline
